Stop an alert group from notifying a channel by removing one attachment. Parameters: attachment_id (required) is the id column of get_notification_channels with scope=attached (the default), one row per channel, alert group and severity; it is NOT a channel id, and the tool refuses channel ids because the API would delete the channel itself. alert_group_id (optional, default none) cross-checks that the attachment belongs to that group (the id from get_alert_groups). breach and threat are separate attachments, so removing both takes two calls. Repeating is harmless: the second call is refused because the attachment is gone. Requires a delete-scope token: a write-scope token cannot detach. Returns the detached attachment id, alert group, channel name and severity, plus a link to notification channels in the result's _meta.reference_url. To delete the channel itself once it has no attachments, use delete_notification_channel. Never repeat secrets (webhook URLs, routing keys, headers) back to the user; this tool does not return them.
