Hand off an alert that someone already owns to another user. Use it only for alerts that already have an owner (the claim field on the alert in get_alerts shows the current owner); an alert nobody has acknowledged cannot be reassigned, so call acknowledge_alert first. When the alert has no owner, the error says whether get_alerts lists that exact alert in the last hour, so wrong ids are reported as an unknown alert rather than an unowned one. Parameters: alert_group_id, rule_id and rule_type (all required; copy them from the alert in get_alerts), and exactly one of owner_email or owner_user_id naming the new owner. Prefer owner_email: it is matched case-insensitively against active users in the org, so no user id lookup is needed. The new owner must have the editor or admin role to respond to alerts. Requires a write-scope token, and the caller must be an org admin or the alert's current owner. Last9 does NOT notify the new owner; tell the user to let them know. Returns the new claim: owner name and email, claimed_at (Unix seconds) and muted_until, plus a link to Alerting.
