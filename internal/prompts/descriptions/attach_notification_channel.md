Route an existing notification channel to one alert group so alerts from that group notify it. The channel must already exist: create it once with create_notification_channel and reuse its id, or find ids with get_notification_channels scope=channels. Parameters: channel_id (required; a channel id, not an attachment id), alert_group_id (required; the id from get_alert_groups), severity (required: breach, threat or both). breach and threat are separate attachments: each severity routes independently, and both makes two attach calls and reports each attachment id. Attaching the same channel, group and severity again is safe (idempotent). Attachments copy the channel's delivery settings (headers, certificate, mentions) at attach time; if the channel's settings change later, reattach. Requires a write-scope token whose owner is an editor or admin. Returns the attachment id(s), alert group and severity, plus a link to notification channels in the result's _meta.reference_url; use an attachment id with detach_notification_channel (also listed by get_notification_channels with scope=attached). Never repeat secrets (webhook URLs, routing keys, headers) back to the user; this tool does not return them.
