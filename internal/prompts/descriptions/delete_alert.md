Permanently delete a Last9 alert rule from its owning alert group. Use get_alert_config first to verify entity_id, the exact rule ID, notification coverage, runbook/links, and whether another rule depends on its KPI. To clean up, remove test leftovers or act on several rules at once, act only on rules whose created_via is last9-mcp (shown by get_entity_alert_rules); remove any other rule only when the user names that specific rule or explicitly says to include ones created elsewhere. Summarize the operational impact and only call this tool after the user explicitly confirms deletion. It first checks that the rule exists and belongs to entity_id, and refuses without deleting anything otherwise. Deletion requires a delete-scope token (a write-scope token gets 403) and does not promise cleanup of a separately managed KPI. Returns deletion status and a link to Alerting.
