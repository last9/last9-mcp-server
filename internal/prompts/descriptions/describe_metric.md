Describe 1–10 exact metric names before constructing PromQL: metadata type/unit/help, observed label keys, and conservative query recommendations. Read-only; never queries a datasource directly.

Parameters:
- `metric_names` (required): array of 1–10 names, each at most 256 bytes. No selectors, expressions or default; all names are validated before I/O.
- `datasource` (optional): defaults to the configured datasource. An exact or safe closest match is used; ambiguous names return candidates without querying. A separate content block names a default or closest match.

Returns `metrics`, one entry per input: `name`, `type` (counter/gauge/histogram/summary/unknown), `inferred`, optional `unit`/`help`, `label_keys`, `recommended_query`, and `notes`. An empty recommendation means more evidence is needed. Missing metadata does not prove a metric is absent. Conflicting definitions remain unknown instead of selecting the first. Authorization, cancellation and operational metadata errors fail the call; unsupported metadata permits explicitly inferred naming fallbacks.

Metadata takes precedence over suffixes. `_sum`/`_count` are ambiguous without family evidence. Verified counters use `rate(metric[5m])`; inferred counters require verification first. Never apply rate()/increase() to gauges, including pre-windowed gauges: read the last value or use `avg_over_time` for an ordinary gauge. Summary quantiles and known trace latency families are selected directly (trace p95 uses `quantile="p95"`); never average quantiles into a wider-window percentile. Classic histograms use `histogram_quantile` only with observed bucket labels. When buckets are not observed, a current-time native sample count is checked; verified native histograms use the metric directly in `histogram_quantile` over `rate`. Missing buckets alone do not prove native data. No bucket series is fabricated. Five minutes is an example query window; adjust it to the metric's cadence and requested range.

Labels are observed, not exhaustive: metric-scoped discovery looks back 60 minutes, widening once to 5760 minutes (4 days) only when empty. Failed label discovery is disclosed. At most 20 keys are returned; keys over 128 bytes are omitted. Help is capped at 1024 bytes, unit at 128 bytes, and JSON output at 256 KiB; notes disclose truncation. Discover names with `prometheus_label_values` using label `__name__`; inspect cadence with `get_metric_status`.
